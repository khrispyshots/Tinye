# Design tokens: Lens-aligned theme

**Status:** Approved - Lens visual direction | **Version:** 2.0 | **Last updated:** 2026-11-14  
**Responsible role:** Design systems lead

## Purpose

Define semantic, responsive and accessible visual values aligned directly with [Lens](https://lens.xyz/).

## Lens Theme Semantic Tokens

| Token | Default value | Usage |
|---|---|---|
| surface.canvas | #FAFAFA | Soft cloud/white background |
| surface.card | #FFFFFF | Elevated white cards |
| surface.tinted | #F2F5F0 | Soft sage-mist panels and goal rows |
| surface.summary | #E3EDDA | Pale sage financial summary card |
| text.primary | #1A1B1E | Deep charcoal ink for headings and primary numbers |
| text.secondary | #5F6368 | Slate grey for supporting copy and labels |
| text.onDark | #FFFFFF | White text on dark buttons and pills |
| accent.fresh | #78A738 | Fresh botanical green for progress and active badges |
| action.primary | #121316 | Deep black/charcoal primary button |
| action.primaryHover | #27272A | Hover on primary button |
| action.secondary | #FFFFFF | Secondary white card button |
| border.hairline | rgba(0,0,0,0.07) | 1px hairline container borders |
| border.control | rgba(0,0,0,0.14) | Form input border |
| progress.track | #E2E8DE | Clean muted track |
| focus.ring | #78A738 | Visible focus indicator |

## Typography (Lens Inter Specification)

```css
font-family: 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
letter-spacing: -0.025em; /* Headlines */
letter-spacing: -0.012em; /* Body and UI */
```
