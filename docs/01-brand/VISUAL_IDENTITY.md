# Visual identity

**Status:** Draft | **Version:** 0.1 | **Last updated:** 2026-11-14  
**Responsible role:** Brand / design leads

> **Selected default interface:** [Friendly Green revision 4](../02-design/concepts/06-friendly-green-lens-v4.png), locked in [design.md](../../design.md) and [ui.md](../../ui.md). The historical primitive palette below records the original brief; use the root semantic values for the current app. Final bespoke logo/cultural review remain pending.

## Purpose

Define consistent visual hierarchy and colour intent.

## Assumptions and dependencies

This is a documentation proposal, not an implemented or approved product. The master specification and owner approval govern scope. MVP means the proposed testnet release; later features require separate acceptance. Terms and shared states follow the [product requirements](../00-product/PRODUCT_REQUIREMENTS.md).

## Palette and use

| Primitive | Hex | Role |
|---|---|---|
| Forest | #174D38 | Primary action/background for white label |
| Emerald | #32A879 | Decorative progress, never assumed readable with white text |
| Sage | #E5F0E8 | Selected or quiet positive surface |
| Cream | #F8F9F6 | Main background |
| White | #FFFFFF | Card surface |
| Ink | #202923 | Primary text |
| Muted | #68736C | Secondary text subject to measured contrast |
| Border | #E7EBE6 | Decorative separator, not sufficient as sole input boundary |
| Warning proposed | #855500 | Warning text with icon/label |
| Danger proposed | #B42318 | Error/destructive text with icon/label |

Neutral surfaces dominate. Use green to guide attention, not to decorate every card. Financial numbers use Geist (Inter fallback), tabular numerals and medium/semibold weights. Photography is optional, human and consented; never show a fictional customer or activity as real.

## Acceptance

Semantic tokens, pairing-specific contrast and dark mode specifications live in DESIGN_TOKENS. Icons require labels where meaning is ambiguous. Charts use stroke patterns and text legends. Final wordmark, font licences, image rights and cultural statements need review before publishing.
